# Upstream gnome-shell-sass files

These files are copied unmodified from gnome-shell tag `51.1`,
`data/theme/gnome-shell-sass/` (GPL-2.0-or-later, © the GNOME Shell authors).
Do not edit them: re-copy from upstream when moving to a newer GNOME release,
so a diff against upstream stays empty.

They are written for St, GNOME Shell's toolkit. `../_st.scss` supplies the
`st-*()` colour functions they call, in a form GTK's CSS understands.
